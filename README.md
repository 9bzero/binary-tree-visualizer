# Binary Tree Visualizer

Interactive **Binary Search Tree** visualizer — insert, delete, and traverse with step-by-step animations.

## Features

- Insert and delete nodes with smooth SVG animations
- Traversal modes: Inorder, Preorder, Postorder, Level-order
- Node highlighting during traversal
- Auto-balancing toggle
- Tree stats: height, node count, balance factor

## Operations

| Operation | Average | Worst Case |
|---|---|---|
| Insert | O(log n) | O(n) |
| Delete | O(log n) | O(n) |
| Search | O(log n) | O(n) |
